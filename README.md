# Transfer Compass

Transfer Compass is a web app to help students plan and track their college transfer applications in one clean, organized dashboard.

## Features (in progress)

- Landing page with CTA to a central dashboard
- Sections for:
  - **Dashboard** – overview of schools, deadlines, and essays
  - **Colleges** – list of target schools and requirements
  - **Deadlines** – key dates for each application
  - **Essays** – prompts, drafts, and completion status

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- Deployed locally (production hosting coming soon)
